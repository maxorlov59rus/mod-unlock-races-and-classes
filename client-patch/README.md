# Клиентский патч: расы Cata+/MoP для 3.3.5a

Бинарные MPQ-патчи в репозиторий не включаются (их нужно собирать локально).
Здесь лежат **исходники DBC-строк** и пошаговая инструкция.

## Что даёт патч

- Расы: **Гоблин (9)**, **Ворген (22)**, **Пандарен (24 Альянс / 25 Орда)**
- Меню NPC-мастера начнёт их показывать, когда в `UnlockRacesClasses.conf`:

  ```
  UnlockRacesClasses.EnableNewRaces = 1
  ```

⚠️ Без клиентского патча включать флаг **нельзя** — клиенты будут крашиться при виде этих рас.

## Инструкция сборки MPQ

### Шаг 1. Инструменты

- [WDBX Editor](https://github.com/mooreddie/WDBX-Editor) (или DBCUtil + любой CSV-редактор)
- [MPQ Editor](https://www.zezula.net/en/mpq/download.html) (Ladik's MPQ Editor)

### Шаг 2. Правка DBC

1. Извлеките из клиентских MPQ (Data/patch-3.MPQ и базовые):
   - `DBFilesClient/ChrRaces.dbc`
   - `DBFilesClient/CharBaseInfo.dbc`
2. Откройте `ChrRaces.dbc` в WDBX Editor, добавьте строки из
   `dbc/ChrRaces_additions.csv` (файл содержит описание колонок).
   - **DisplayID**: либо оставьте оригинальные Cata/MoP ID (тогда нужны модели, шаг 3), либо временно подставьте любой существующий ID модели 3.3.5a для проверки логики.
3. Откройте `CharBaseInfo.dbc`, добавьте строки из
   `dbc/CharBaseInfo_additions.csv` (одна строка = одна допустимая комбинация раса/класс).
4. Сохраните оба файла.

### Шаг 3. Модели

Для настоящих моделей гоблина/воргена/пандарена:

1. Возьмите клиент Cata/MoP, извлеките M2/BLP/Skin файлы нужных DisplayID
   (см. ChrRaces_additions.csv)
2. Конвертируйте под 3.3.5a (M2 вер. 17): используйте
   [Adspartan's Model Changer / M2 converter](https://model-changing.net/) — на форуме Model-Changing есть готовые порты этих рас для 3.3.5a, рекомендуем взять их
3. Упакуйте модели с оригинальными путями (путь берётся из M2-файла)

### Шаг 4. Сборка MPQ

1. Создайте папку-структуру:

   ```
   patch-urc/
   └── DBFilesClient/
       ├── ChrRaces.dbc        (исправленный)
       └── CharBaseInfo.dbc    (исправленный)
   └── Character/              (модели, если делали шаг 3)
   ```

2. В Ladik's MPQ Editor: **New Archive (patch)** → версия MPQ v2/3 →
   добавьте содержимое папки → сохраните как `patch-urc-4.MPQ`
   (номер 4+ чтобы грузился после patch-3)
3. Положите в папку `Data/` клиента
4. В `realmlist.wtf`/launcher-патчлисте добавьте загрузку патча
   (для 3.3.5a достаточно имени `patch-urc-4.MPQ` — клиент грузит `patch-%d` автоматически)

### Шаг 5. Сервер

- `UnlockRacesClasses.EnableNewRaces = 1` в конфиге worldserver
- Перезапустите worldserver
- В меню NPC появятся Гоблин, Ворген и Пандарен

## Проверка

- [ ] Создайте тестового персонажа → смените расу на Гоблина у NPC
- [ ] Перезайдите — модель гоблина отображается
- [ ] Ворген (Альянс) / Пандарен — фракция переключается корректно
- [ ] Клиенты БЕЗ патча не крашатся (флаг на сервере должен быть выключен)
