# Совместимость сервер / база / клиент

Модуль разработан для связки **AzerothCore (сервер) + 3.3.5a клиент** — самой распространённой конфигурации. Ниже описано, что делает модуль для совместимости и что требуется на каждом уровне.

## 1. Сервер (worldserver)

- Все комбинации раса/класс разблокированы на уровне сервера, но **меню NPC показывает только то, что клиент способен отобразить**:
  - Классы MoP+ (Monk) и Legion+ (Demon Hunter) скрыты для WotLK-сборок
  - Расы Cata+/MoP (Goblin, Worgen, Pandaren) скрыты — у клиента 3.3.5a нет их моделей и данных
- Проверка расширения берётся из опции `Expansion` в `worldserver.conf` (по умолчанию 2 = WotLK).

## 2. База данных

Модуль использует обе БД:

| БД | Таблица | Назначение |
|---|---|---|
| `world` | `creature_template`, `creature` | NPC-мастер и его спавны в 8 столицах (`data/sql/db-world/unlock-races-classes.sql`) |
| `characters` | `mod_unlock_races_classes_specs` | Персистентность выбранной специализации (переживает релог) (`data/sql/characters/unlock-races-classes.sql`) |

**Важно:** примените оба SQL-файла в соответствующие базы. Если таблица специализаций в characters-БД не создана, спеки будут сбрасываться при каждом входе.

## 3. Клиент (3.3.5a)

Клиент 3.3.5a из коробки поддерживает классы 1–9 и 11 (включая Рыцаря смерти) — поэтому **смена класса на любой из них и смена расы среди 10 классических рас работают на чистом клиенте без патчей**.

Кастомные специализации (Blademaster, Necromancer) используют **существующие** спеллы и ауры сервера, поэтому дополнительных клиентских файлов не требуют.

### Если вы хотите включить Cata+/MoP расы (Гоблин, Ворген, Пандарен)

Модуль поддерживает их из коробки:

1. Соберите клиентский патч по инструкции `client-patch/README.md` (DBC-исходники лежат в `client-patch/dbc/`)
2. Включите `UnlockRacesClasses.EnableNewRaces = 1` в конфиге worldserver
3. Перезапустите сервер — расы появятся в меню NPC, фракции переключаются автоматически (Ворген/Пандарен-Альянс → Альянс; Гоблин/Пандарен-Орда → Орда)

⚠️ Не включайте флаг без патчей на клиентах — будет краш.

### Если вы хотите включить MoP+/Legion+ классы (Monk, Demon Hunter)

Понадобятся кастомные патчи клиента (MPQ), а именно:

1. **CharBaseInfo.dbc** — открыть допустимые комбинации раса/класс на стороне клиента
2. **ChrClasses.dbc / ChrRaces.dbc** — записи для новых классов/рас
3. **Модели и иконки** — для Monk/Demon Hunter (MPQ с M2/BLP из новых версий, конвертированных под 3.3.5a)
4. Соответствующие правки ядра (хендлеры класса, таланты)

## Проверка совместимости (чек-лист)

- [ ] `Expansion = 2` в `worldserver.conf`
- [ ] Применён `data/sql/db-world/unlock-races-classes.sql` (world DB)
- [ ] Применён `data/sql/characters/unlock-races-classes.sql` (characters DB)
- [ ] Клиент 3.3.5a без патчей: смена расы (10 классических рас) и класса (1–9, 11) работает
- [ ] Специализации: ауры восстанавливаются после релога
- [ ] (опционально) Клиент с патчем `patch-urc-4.MPQ` + `EnableNewRaces = 1`: Гоблин/Ворген/Пандарен работают
